# AI Factory - Brand Identity & Advertising Campaign


---

## О компании

**AI Factory** - агентство нового поколения, специализирующееся на создании AI-видеоконтента для социальных сетей. Компания разрабатывает уникальные цифровые аватары на основе фотографий клиентов, пишет сценарии и производит готовые видеоролики для публикации.

**Сфера:** AI-продакшн / Digital-маркетинг  
**Целевая аудитория:** бизнес, блогеры, бренды, которым нужен масштабируемый видеоконтент  
**УТП:** Один человек → бесконечный контент через AI-аватар
